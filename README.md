# Aditya K — Portfolio

A futuristic aerospace / robotics-HUD portfolio for Aditya K, an Electronics & Communication Engineering student focused on embedded systems, UAVs, and intelligent hardware.

Built with **React 19 + Vite + Tailwind CSS v4**.

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL.

## Build

```bash
npm run build
npm run preview
```

## Stack

- React 19 + React DOM 19
- Vite 8
- Tailwind CSS v4 (`@tailwindcss/vite`)
- TypeScript 5.7
- Fonts: Chakra Petch, Sora, JetBrains Mono (Google Fonts)
